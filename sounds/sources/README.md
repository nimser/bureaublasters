# Sources audio importées

Déposer les enregistrements ou sons synthétisés utilisés par les sources `file` de `sounds/tools/effects.json` dans ce répertoire. La clé `path` est relative à ce répertoire.

Ne versionner que des fichiers autorisés à la redistribution. Chaque source doit avoir une licence, une page d’origine ou une fiche interne de provenance et l’attribution applicable. Pour une création interne, conserver aussi l’auteur et la recette de synthèse ou les conditions d’enregistrement dans une fiche Markdown.

Aucun son de banque n’est fourni avec cet outil. Les fichiers préparés et validés sont publiés dans `sounds/library/`, pas dans ce répertoire.
